# hobbit-sim

Simuliert Simons Magic-Decks (The Hobbit, HOB) mit der Forge-Engine KI gegen KI.

- `decks/` – Decks im Forge-Format (`.dck`). Neues oder geändertes Deck pushen → Simulation startet automatisch.
- `results/README.md` – Matchup-Tabelle und Rangliste der letzten Simulation.
- `results/latest.json` – Rohdaten für die spätere App.
- Manuell starten: Actions → „Simulate matchups“ → Run workflow (Spiele pro Matchup, optional Deckauswahl).

Forge-KI spielt solide, aber nicht wie ein starker Mensch: Siegquoten sind Richtwerte.
